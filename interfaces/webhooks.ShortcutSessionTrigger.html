    Interface ShortcutSessionTrigger

    What started a session. The known shapes are the ShortcutInteractionTrigger variants, and every one of them is assignable here. The session is the event, so only the entity reference is required and each per-type field is checked for its type, never for this version's enum values or for the combination a known type usually carries: a value Shortcut adds within envelope v1 must not stall the session with a 400. Narrowing on type therefore leaves the per-type fields optional.
