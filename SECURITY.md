# Security Policy

This policy applies to all open source code repositories hosted by Shortcut, including the packages and artifacts built from them.

## Reporting a Vulnerability

Report security vulnerabilities by email to [security@shortcut.com](mailto:security@shortcut.com).

Do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.

Please include:

- The affected repository and version
- A description of the vulnerability and its impact
- Steps to reproduce or a proof of concept

Vulnerabilities in third-party dependencies should be reported to the maintainers of those dependencies.

## Our Process

Shortcut's security team reviews every report and assesses its severity based on exploitability and impact. Confirmed vulnerabilities are remediated according to that assessment of severity.

Vulnerability details are kept confidential until a fix is released. Following remediation, Shortcut may publish a security advisory, release notes, or a CVE.

## Unmaintained Repositories

Archived repositories are no longer maintained and do not receive security fixes.
